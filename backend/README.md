# CadRecon Ultra — дополнительный локальный пакет PaddleOCR + OpenCV

> **Не является обязательной частью сайта.** Единственный хостинг CadRecon — GitHub Pages; обычная и точная браузерная обработка работают **без Python и сервера**. Дополнительный модуль пользователь может самостоятельно установить **на этом же ПК**. Внешние URL для обработки КД запрещены. [Правило архитектуры](../docs/STATIC_PAGES_ARCHITECTURE.md), [инструкция Ultra](../docs/ULTRA_WINDOWS_INSTALLER.md).

Этот модуль запускается отдельно от GitHub Pages на Windows/Linux на компьютере пользователя и позволяет применять альтернативный OCR. Более высокая точность относительно браузерной версии не доказана на независимом реальном корпусе.

## Установка

Python 3.10–3.12 рекомендуется (проверьте совместимость конкретной платформы и PaddlePaddle).
В отдельном виртуальном окружении из корня репозитория:

\`\`\`powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -U pip
# PaddlePaddle CPU/GPU — согласно https://www.paddlepaddle.org.cn/install/quick
python -m pip install paddlepaddle
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.server:app --host 127.0.0.1 --port 8765
\`\`\`

При первом запуске OCR автоматически скачивает веса моделей, затем использует локальные файлы. Предусмотрен русский PP-OCRv5.

## Использование

В CadRecon: «Усиленное распознавание» → URL \`http://127.0.0.1:8765\` → кнопка отправки текущего листа. Лист передаётся только после подтверждения пользователя; третьи стороны не участвуют. Подключение поддерживается только к `localhost` / `127.0.0.1` на этом же компьютере, как необязательная функция.

**Никогда не выставляйте сервис в интернет**: внешний сервер не входит в архитектуру продукта. Для локального модуля можно задать `CADRECON_TOKEN`; лист передается только на loopback после явного подтверждения. Не настраивайте WAN/Tailscale/внешние reverse proxy для этого режима.

## Ограничения

Алгоритм включает текст PaddleOCR PP-OCRv5 и LSD/Hough/OpenCV, классификацию простых контуров. Это всё ещё набор гипотез, не полноценное распознавание норм ЕСКД или гарантированная точность КМ/КМД. Корректность OCR/геометрии проверяется по чертежу. На больших сканах без GPU может потребоваться значительное время и RAM. GitHub Pages не может выполнять Python-сервер и сам по себе не активирует модели PaddleOCR.
