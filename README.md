# CadRecon — браузерный конвертер PDF / скан → 2D CAD

**Архитектура: только GitHub Pages, без собственного сервера.** Импорт PDF/сканов, OCR, восстановление и DXF выполняются в браузере пользователя. Кнопка **«Точное распознавание в браузере»** запускает усиленный локальный конвейер; модели RU/EN загружаются браузером по требованию (GET, без отправки чертежей). Для особо сложных листов **можно дополнительно** установить Ultra на свой ПК, но для основной программы он не нужен. Внешние OCR-адреса запрещены. [Техническое архитектурное решение](docs/STATIC_PAGES_ARCHITECTURE.md).

**Код:** https://github.com/kappamaag-crypto/CadRecon  
**Сайт после включения Pages:** https://kappamaag-crypto.github.io/CadRecon/

CadRecon — редактор плоских CAD-чертежей с импортом PDF, JPG, PNG и TIFF, восстановлением отдельных графических объектов, OCR, ручной правкой и экспортом DXF. Основное приложение полностью браузерное: GitHub Pages предоставляет лишь статические ресурсы.

## Разработка W1–W3 (22 ноября 2026)

**Срез проверенных изменений:** [измеренный отчёт W1/W2/W3](docs/W1_W2_W3_IMPLEMENTATION_STATUS.md).

- **Векторный PDF:** исправлен PDF.js 5.x packed DrawOPS; сохранены линии, замкнутые контуры, проверяемое восстановление четырех четвертей Bezier в CIRCLE; остальные cubic не разбиваются в грубые сегменты, а сохраняются как редактируемый `bezier` / DXF SPLINE.
- **Единицы DXF:** лист без калибровки экспортируется с `$INSUNITS=0`, а не с ложным указанием миллиметров; DXF SPLINE проходит независимый `ezdxf` audit.
- **Растр:** дополнительный градиентный детектор окружностей на пересечениях; исходный синтетический эталон теперь даёт 1 окружность вместо 0, при центре 2 px от известного. **Не является показателем качества любых сканов**.
- **Online Accurate (пилот):** добровольно включаемая асинхронная обработка на отдельно запущенном однопользовательском Python сервере с токеном, подтверждением отправки и удалением результата. [Инструкция](backend/ONLINE_PILOT.md). Это **не развёрнутый публичный SaaS**, не высокоточный ансамбль OCR и не гарантированное восстановление ЕСКД.
- **Автоматические проверки:** браузерный W1 accuracy gate, W0 baseline, W3 fixture, API/consent tests и DXF parser; оставшиеся критические пробелы и real benchmark — в [ROADMAP](ROADMAP.md).

Внешний Online Accurate backend не запускается на GitHub Pages. Для работы с коммерческой документацией перед отправкой на любой внешний сервер необходимо подтвердить права и условия обработки. Прямого нативного DWG/CDW по-прежнему нет; требуется лицензированный CAD-коннектор. Автоматическую точность произвольного скана 100% не заявляем.

## Реализовано

- Многостраничный PDF (первые 40 страниц) через PDF.js, отдельные редактируемые векторные отрезки из PDF-paths (до 30 000 на страницу).
- Растровые PDF/JPG/PNG/TIFF и автоматическое распознавание прямых линий в Web Worker (приближённая Hough-векторизация, поиск изолированных окружностей и объединение коллинеарных отрезков).
- извлечение редактируемого текста векторных PDF и OCR русских и английских надписей через Tesseract.js, с возможностью исправить каждую распознанную TEXT-сущность.
- CAD-инструменты: LINE, POLYLINE, CIRCLE, ARC, DIMENSION, AXIS, LEADER, TEXT, полигоны, таблицы, штамп и конструктор 12 типов обозначений ЕСКД.
- Редактирование текста, точек, радиуса, размера, слоёв, перенос/удаление; привязка, сетка, измерения, панорама, масштаб.
- Калибровка по известному размеру и режим сравнения «оригинал / CAD».
- DXF текущего листа и ZIP с DXF всех листов (отдельные примитивы и объекты DIMENSION с блоком отображения), проект JSON, IndexedDB: автосохранение, Undo/Redo и 8 резервных копий.
- Автоматическое выделение кандидатов размерных цепочек по OCR-тексту и выносным линиям; группировка цепочек, диагностика несовпадения размера и геометрии, индивидуальная проверка каждого кандидата.
- Библиотека 12 семантических графических шаблонов ЕСКД; экспорт обозначений как редактируемых блоков INSERT.
- Базовая проверка масштаба, неподтверждённых объектов, слоёв и нулевых отрезков.
- Подробная инструкция: [Размерные цепочки и ЕСКД](docs/ESKD_AND_DIMENSIONS.md).

## Запуск

Нужен Node.js 22+.

\`\`\`bash
git clone https://github.com/kappamaag-crypto/CadRecon.git
cd CadRecon
npm install
npm run dev
npm test
npm run build
npx playwright install chromium
npx playwright test
\`\`\`

Для публикации откройте в GitHub **Settings → Pages → Source → GitHub Actions**. Workflow Pages выполняет тесты, сборку и развёртывание на https://kappamaag-crypto.github.io/CadRecon/ . Путь Vite \`/CadRecon/\` уже настроен.

## Рабочий порядок

1. Загрузить PDF или скан. Для векторных PDF штрихи будут извлечены при импорте, для сканов нажать «Автообводка линий».
2. При необходимости выполнить OCR или запустить «Восстановить размерные цепочки и ЕСКД». Перейти в «Распознавание», проверить все предложенные объекты. Отдельно доступны 12 шаблонов обозначений.
3. Использовать «Калибровка»: указать две точки с известным размером в миллиметрах. **Обязательно сверить второй независимый контрольный размер.**
4. Исправить контуры, вручную построить реальные размерные объекты, выноски, оси, надписи, штамп. Пометить проверенные объекты в свойствах.
5. Проверить режим «До/после» и вкладку аудита.
6. Экспортировать DXF и проверить в AutoCAD / КОМПАС-3D, затем сохранить DWG / CDW в соответствующей системе. Отдельно экспортировать JSON проекта на диск.

## Ограничения точности

**Автоматическая векторизация не равнозначна перерисовке вручную.** На сканах текст, размерные цепочки, допуски, сварные обозначения и специфические детали требуют сверки/дочерчивания. Нельзя использовать автоматически полученный DXF для производства металлоконструкций без инженерной проверки. Отметка \`verified\` отражает проверку пользователем, не заменяет нормоконтроль.

Таблицы/штампы в DXF пока представлены редактируемыми линиями и текстом, а штриховки — редактируемыми HATCH-объектами. DWG/CDW напрямую браузер не создаёт. Сканы могут требовать исправления перспективы и разных растяжений по осям. OCR загружает языковые модели из публичных источников (сам документ на сервер не отправляется). Файлы пользователя не включаются в публичный GitHub-репозиторий.

## Данные и резервные копии

Проекты хранятся в IndexedDB конкретного браузера. Очистка данных сайта может удалить и проекты, и резервные копии: сохраняйте отдельные JSON. Серверного хранилища чертежей нет.

## Повышенная точность: исправление кодировки и локальные модели

Исправлено типовое повреждение PDF-текста Windows-1251, например «Áîëò» → «Болт».
Распознавание линий в браузере работает в деталях на перекрывающихся участках исходного скана,
а не на ранее уменьшенном до 1100 px изображении. OCR Tesseract настроен на разрозненные подписи.
Все исправления помечаются как требующие сверки.

Для сложных чертежей можно **самостоятельно скачать и установить дополнительный локальный пакет Ultra**:
PaddleOCR PP-OCRv5 (русский) + OpenCV LSD/Hough, контуры и отверстия.
[Инструкция установки Ultra на собственный компьютер](docs/ULTRA_WINDOWS_INSTALLER.md).
В интерфейсе необязательная секция «Дополнительно: Ultra на своём компьютере» → localhost → локальный токен. Из браузера **невозможно выбрать внешний OCR-сервер**: допускаются только localhost/127.0.0.1, и передача в локальный модуль требует подтверждения.

**Ограничение:** GitHub Pages остаётся статической веб-площадкой. Без самостоятельно установленного Ultra на компьютере пользователя **PaddleOCR** не работает, но стандартные функции PDF.js, браузерная обводка и Tesseract OCR доступны без него. Нет обещания 100% автоматического
восстановления всех размеров, символов ЕСКД и линий из любого скана.
Для применения на производстве нужна проверка геометрии и оформление в CAD.
