# CadRecon — браузерный конвертер PDF / скан → 2D CAD

**Код:** https://github.com/kappamaag-crypto/CadRecon  
**Сайт после включения Pages:** https://kappamaag-crypto.github.io/CadRecon/

CadRecon — редактор плоских CAD-чертежей с импортом PDF, JPG, PNG и TIFF, восстановлением отдельных графических объектов, OCR, инструментами ручной правки и экспортом DXF. Всё работает в браузере, без сервера для загрузки чертежей.

## Реализовано

- Многостраничный PDF (первые 40 страниц) через PDF.js, отдельные редактируемые векторные отрезки из PDF-paths (до 30 000 на страницу).
- Растровые PDF/JPG/PNG/TIFF и автоматическое распознавание прямых линий в Web Worker (приближённая Hough-векторизация).
- извлечение редактируемого текста векторных PDF и OCR русских и английских надписей через Tesseract.js, с возможностью исправить каждую распознанную TEXT-сущность.
- CAD-инструменты: LINE, POLYLINE, CIRCLE, ARC, DIMENSION, AXIS, LEADER, TEXT, полигоны, таблицы и штамп.
- Редактирование текста, точек, радиуса, размера, слоёв, перенос/удаление; привязка, сетка, измерения, панорама, масштаб.
- Калибровка по известному размеру и режим сравнения «оригинал / CAD».
- DXF текущего листа и ZIP с DXF всех листов (отдельные примитивы и объекты DIMENSION с блоком отображения), проект JSON, IndexedDB: автосохранение, Undo/Redo и 8 резервных копий.
- Базовая проверка масштаба, неподтверждённых объектов, слоёв и нулевых отрезков.

## Запуск

Нужен Node.js 22+.

\`\`\`bash
git clone https://github.com/kappamaag-crypto/CadRecon.git
cd CadRecon
npm install
npm run dev
npm test
npm run build
npx playwright install chromium
npx playwright test
\`\`\`

Для публикации откройте в GitHub **Settings → Pages → Source → GitHub Actions**. Workflow Pages выполняет тесты, сборку и развёртывание на https://kappamaag-crypto.github.io/CadRecon/ . Путь Vite \`/CadRecon/\` уже настроен.

## Рабочий порядок

1. Загрузить PDF или скан. Для векторных PDF штрихи будут извлечены при импорте, для сканов нажать «Автообводка линий».
2. При необходимости выполнить OCR, проверить все строки.
3. Использовать «Калибровка»: указать две точки с известным размером в миллиметрах. **Обязательно сверить второй независимый контрольный размер.**
4. Исправить контуры, вручную построить реальные размерные объекты, выноски, оси, надписи, штамп. Пометить проверенные объекты в свойствах.
5. Проверить режим «До/после» и вкладку аудита.
6. Экспортировать DXF и проверить в AutoCAD / КОМПАС-3D, затем сохранить DWG / CDW в соответствующей системе. Отдельно экспортировать JSON проекта на диск.

## Ограничения точности

**Автоматическая векторизация не равнозначна перерисовке вручную.** На сканах текст, размерные цепочки, допуски, сварные обозначения и специфические детали требуют сверки/дочерчивания. Нельзя использовать автоматически полученный DXF для производства металлоконструкций без инженерной проверки. Отметка \`verified\` отражает проверку пользователем, не заменяет нормоконтроль.

Таблицы/штампы в DXF пока представлены редактируемыми линиями и текстом, а штриховки — редактируемыми HATCH-объектами. DWG/CDW напрямую браузер не создаёт. Сканы могут требовать исправления перспективы и разных растяжений по осям. OCR загружает языковые модели из публичных источников (сам документ на сервер не отправляется). Файлы пользователя не включаются в публичный GitHub-репозиторий.

## Данные и резервные копии

Проекты хранятся в IndexedDB конкретного браузера. Очистка данных сайта может удалить и проекты, и резервные копии: сохраняйте отдельные JSON. Серверного хранилища чертежей нет.

## Развитие

Следующий этап: распознавание размеров как смысловых объектов, сложных обозначений ЕСКД, полноценный DXF HATCH и таблиц, многоточечная калибровка, автоматическое слияние контуров и тестирование совместимости на живых PDF/DWG в AutoCAD и КОМПАС.
