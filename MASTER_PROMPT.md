## Жёсткие требования

- Основной сайт размещён на **GitHub Pages** и самостоятельно обрабатывает PDF/PNG/JPG/TIFF локально в браузере. Чертежи **не отправлять** на внешний SaaS, HTTP API или сервер проекта. Допускается скачивание пользователем необходимых открытых моделей/пакетов на собственное устройство.
- **3D, STEP, A3D, M3D, 3D-коннекторы и генерирование 3D — вне scope.** Ручной 2D CAD (W4) вторичен: он помогает оператору поправлять результат реконструкции.
- **Основной выход — редактируемый DXF**, а не картинка на подложке. DWG/CDW не выдавать за рабочий экспорт без подтверждённого лицензированного конвертера/SDK и contract tests.
- Ultra — **только добровольная установка на ПК пользователя**, с выбором каталога, локальным loopback API, ограничениями памяти, аутентификацией и без общей серверной инфраструктуры.
- Отделять реальные PDF-операторы, пиксельное свидетельство, гипотезу Hough/OCR, CAD-сущность и инженерное решение об утверждении. **Никогда** не выставлять `verified=true` автоматически, не исправлять «похожую» цифру размера молча, не замыкать линии через отсутствующие чернила.
- Пиксели, координаты листа и миллиметры — разные единицы. Калибровка по известному размеру с независимой проверкой обязательна для инженерных мм. Консервативный отказ лучше ложной геометрии.
- Прозрачные сканы должны рендериться на белом фоне и в OCR, и в обводке. Крупные листы — тайлами с источниковыми bbox и предупреждениями о неполном охвате.
- Защищать проектные чертежи: не добавлять секретную документацию в открытый репозиторий или GitHub Actions artifacts; для испытаний — воспроизводимые синтетические эталоны либо отдельно разрешённые обезличенные реальные изображения.

## Приоритеты

**P0/W1:** нативная PDF геометрия, корректные paint/clip/CTM, кривые, XObjects, проверка отсутствия фантомных линий и сохранение DXF сущностей.

**P0/W2:** OCR RU/EN, повернутые размеры, допуски/диаметры/штампы, видимые альтернативы OCR, шкала confidence 0–1, сохраняемые bbox, недеструктивное повторное чтение.

**P0/W3:** ложные отрезки, пересечения, качество растровых штрихов, независимые контуры, штриховые/осевые, прекращение незаконного соединения зазоров, пересчёт свидетельств после любых геометрических объединений.

**P1/W4–W5:** удобство панели проверки и ручные 2D инструменты/ЕСКД, но не за счёт стабильности распознавания. **P2/W6:** необязательный Ultra на Windows.

## Definition of Done для каждого изменения

1. Проверить реальную проблему на `main` и создать минимальный regression test **до/вместе** с кодом. Не переписывать реализованную функцию только потому, что она не упомянута в старом плане.
2. Если затронуты координаты/этажность PDF, Hough, OCR или DXF — проверить положительные и негативные случаи: вертикаль, наклон, перекрестие, белый зазор, почти параллельные линии, прозрачный фон, обрезанные объекты, разные разрешения.
3. `npm test`, `npm run build`, независимое открытие DXF, Playwright E2E, GitHub Actions. Если тестовая среда недоступна — явно написать, какие проверки **не выполнялись**.
4. Не говорить «точность 99%» без разрешённого независимого корпуса, разметки CAD↔scan и измеренных precision/recall/F1, CER/WER и геометрических ошибок в мм. Синтетические тесты — только регрессия, а не подтверждение промышленного качества.
5. Проверить отсутствие регрессии UX, возможность Ctrl+Z/отмены, лимиты объектов/тайлов, память, загрузку/сохранение и сохранение source evidence.
6. Указать в отчёте SHA/PR, статус CI, изменённые файлы, фактически наблюдаемый результат, нерешённые риски, следующий приоритет.

## Статусы реализации

Различать **PLANNED**, **IMPLEMENTED_IN_REPO**, **CI_PASSED_SYNTHETIC**, **PUBLISHED_PAGES**, **RUNTIME_TESTED_ON_REAL_DRAWING**, **ENGINEER_VERIFIED**, **BLOCKED**. Статус `CI_PASSED_SYNTHETIC` не означает `ENGINEER_VERIFIED`.

## Следующий критерий прогресса

Для W3 — сократить ложные Hough-предложения на **фиксированном разрешённом корпусе**, при сохранении подтверждённой полноты истинных контуров и запрета ложных соединений. Для W2 — точность критических размерных OCR-строк, а не только общий confidence Tesseract. Для W1 — PDF clipping и формы/XObject + DXF round-trip. Любую оптимизацию, которая уменьшает количество LINE только за счёт скрытой потери истинных линий, отклонять.
