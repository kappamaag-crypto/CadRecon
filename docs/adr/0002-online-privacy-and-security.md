# ADR-0002 — Онлайн-обработка, приватность, безопасность и хранение

**Статус:** proposed / W0. **Дата:** 2026-11-22. **Приоритет:** P0 для Online Accurate. *Не означает наличие защищённого online backend в текущей версии.*

## Решение

1. **Режим Quick Web**: браузерная обработка PDF/изображения и экспорт. Отдельно предупреждать, что OCR может загружать модель с внешнего CDN; содержимое документа не отправлять на удалённый сервис без согласия. При строгой privacy требуется локальный хостинг языковых моделей/скриптов.
2. **Online Accurate**: перед загрузкой листа — явное информированное согласие с указанием оператора, региона, типа данных, срока хранения, возможных третьих сторон и стоимости/квоты. Отказ оставляет Quick Web доступным. Для секретной КД — локальный Ultra.
3. **Аутентификация/авторизация**: scoped access/tenant isolation, короткоживущие signed upload/download URLs, rate limits и квоты; никакие долгоживущие токены в localStorage, логах, GitHub Actions или URL.
4. **Upload gateway**: magic bytes + MIME, decompression/zip-bomb limits, лимит страниц/пикселей/вложенных объектов, malware scan и изолированные PDF workers с памятью/CPU/time limits; сетевой egress allowlist, не доверять PDF JavaScript и ссылкам.
5. **Пайплайн**: idempotent job IDs, версия алгоритмов, очередь с лимитами CPU/GPU, отмена/retry, progress stream, bounded concurrency, data encryption at rest/in transit, явная кнопка удаления.
6. **TTL**: отдельный ADR утвердит конкретный срок по типам файлов и юрисдикции до первой production-загрузки. Нельзя написать «документы удалены» без проверенной политики удаления и backup purge.
7. **Наблюдаемость**: метрики без текста чертежа, оригинального изображения, токенов и персональных данных; отладочные экземпляры только отдельным opt-in.
8. **Обучение моделей**: документ пользователя не используется в датасете без отдельного согласия; разрешение на облачную обработку ≠ разрешение на обучение.
9. **Локальный Ultra**: `127.0.0.1` default, авторизация при доступе с LAN/Tailscale, TLS и CORS origin allowlist; проверить Local Network Access/Chrome и Firefox отдельно.
10. **Лицензионный контроль**: библиотека/модель/SDK, license SPDX, redistribution, срок обновления, SBOM, security patches. Третьи сервисы отключены по умолчанию.

## Неопределенности / before go-live

- Выбор реального провайдера/региона, хранение backup/recovery, тариф и бюджет GPU; необходимость российского размещения при обработке персональных данных/КД определяется отдельным юридическим анализом.
- Threat model: cross-tenant IDOR, upload bombs, model prompt injection, malicious PDF, SSRF, OAuth scope, model supply-chain, client-side malware, abuse.
- Текущий `backend/server.py` — **локальный прототип с опциональным токеном, без мультиарендной изоляции**, не использовать как открытый production API.
- Security gates: изоляция tenants, лимиты, удаление и отказ от consent, токены/секреты, уязвимости через зависимые библиотеки.
