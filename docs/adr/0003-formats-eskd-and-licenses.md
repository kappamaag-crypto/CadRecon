# ADR-0003 — CAD форматы, ЕСКД и лицензии

**Статус:** proposed / W0. **Дата:** 2026-11-22. **Приоритет:** P0 для DXF, P2 для DWG/CDW.

## Форматы

- **DXF:** основной редактируемый формат первого релиза. R2000 (AC1015) — текущий выбор, позже матрица совместимости R2000/2010/2018 по реальным CAD приемникам. Проверять геометрию, блоки, DIMENSION, линии, hatch, Unicode, единицы и размеры после reopen. Извлечение текстовых/визуальных PDF путей не гарантирует восстановления исходных CAD блоков и параметризации.
- **DWG:** требуется лицензированный SDK/конвертер с условиями для SaaS и распространения (например ODA Drawings SDK). Нельзя просто переименовать DXF в DWG. Любая потеря семантики — report, согласие перед fallback.
- **CDW:** через **локальный Windows адаптер с установленным лицензированным КОМПАС-3D v25/SDK**. Доступность зависит от редакции, API и лицензии; тестировать настоящий CDW после сохранения и повторного открытия в КОМПАС. Веб-приложение само по себе не пишет нативный CDW.
- **JSON проект:** схема v1 сейчас хранит координаты без явной системы единиц; W1 потребует миграции v2 с обратной совместимостью, версии `source` и `review` и сохранением исходников. Никаких бесшумных преобразований.

## ЕСКД

- Ввести `normProfile`: организация, вид чертежа, дата применения, список нормативных документов с **редакцией и датой**.
- Версионируемая таблица правил: ГОСТ 2.104/2.109/2.301/2.302/2.303/2.305/2.306/2.307/2.308/2.309/2.312 и актуализированные ГОСТ Р, **без утверждения действительности всех редакций одновременно**; проверять через Росстандарт/официальные документы перед кодированием.
- Проверка цепей размеров, допусков, обозначений, штампа/разрезов/сварки должна различать `known-good`, `warning`, `unknown`, `unverifiable`. Допусков и точности нельзя «додумывать» по OCR.
- Сохранять полное основание каждого вывода: ссылка на конкретную версию стандарта, пункт после легального доступа, объект, confidence и решение инженера.
- Обязательный тестовый baseline раздельно для OCR текста и семантики; нормы может подтверждать только нормоконтролер.

## Gate

1. DXF: независимый parser + AutoCAD/LibreCAD/КОМПАС manual round-trip на выбранных версиях.
2. DWG/CDW: указаны поставщик и лицензия, подтвержден SDK, матрица версий и типы документов, подписан отчет потерь.
3. ЕСКД: редакция и дата правил, тестовая таблица решений для 20+ регламентированных кейсов, инженерная приемка.
4. Нельзя показывать `verified`/«Соответствует ЕСКД» лишь по отсутствию автоматических warning.
