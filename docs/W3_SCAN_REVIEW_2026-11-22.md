# W3: диагностика разрывов и слабого растрового подтверждения

Дата: 2026-11-22. Работа выполняется целиком в браузере GitHub Pages, без сервера.

## Что добавлено

В разделе «Поиск и аудит» → «Аудит объектов» доступна кнопка «W3: проверить топологию автообводки». Проверка не изменяет проект. Модуль src/scanReview.ts работает с непроверенными LINE происхождения trace, не затрагивает PDF-векторы и вручную созданные объекты.

- Предлагает к проверке близкие (1,25–8 единиц координат листа) почти соосные концы двух разных линий на одном листе и слое.
- Выводит линии с низкой пиксельной опорой, если она записана в объяснении W3 (меньше 35%), либо с очень низким эвристическим баллом, если пиксельная опора неизвестна.
- Позволяет перейти к найденному объекту на листе и сохранить проверочный CSV.
- Использует пространственную сетку для поиска соседних концов вместо полного сравнения всех пар. Ограничивает число видимых замечаний и обработку особо плотных ячеек.
- Не соединяет линии автоматически, не создаёт размеры, не удаляет штрихи и не присваивает verified=true.
- Экспорт CSV защищён от формульной интерпретации пользовательского текста.

## Интерпретация

«Возможный разрыв» — не утверждение, что на бумаге существует сплошной штрих. Размер зазора дан **в координатах листа, НЕ в подтверждённых миллиметрах**, а диапазон поиска фиксирован и эвристичен. Фрагменты могли закончиться на выноске, размере, сварном обозначении, штриховке или видимом пустом месте. «Слабое подтверждение» — не доказательство ложной CAD-линии.

## Требуется далее

Необходимы независимые реальные КМ/КМД для измерения precision, recall и ложных разрывов; затем — контролируемая полуавтоматическая сборка полилиний с проверкой непрерывности исходной краски. На данном этапе автоматическое слияние не выполняется, чтобы не создавать неверные инженерные контуры.

Unit tests: src/scanReview.test.ts. CI: npm test, npm run build, Playwright.

## Интеграция с отчетностью

Проверка включена в сводную Excel-книгу отдельным листом «Диагностика W3», показатели добавлены в «Сводку». Экспорт пакета проекта ZIP содержит «Отчеты/Диагностика_топологии_W3.csv». Никакие результаты не объявляются измерениями в миллиметрах без независимой калибровки.

## Непрерывность исходных пикселей

Алгоритм W3 измеряет максимальный непрерывный участок вдоль LINE без пиксельного подтверждения. Начиная с 12% он уменьшает эвристический балл, но не удаляет саму линию. При доле 20% и больше выводится отдельное предупреждение «Длинный белый участок». Возможна правильная штриховая или штрихпунктирная линия — автоматического соединения/удаления нет. CSV, XLSX и ZIP включают эти диагностические отметки.
