# W4: STRETCH / MIRROR / ARRAY — ограниченные безопасные CAD-инструменты

Статическая GitHub Pages версия; без локального сервера и облачных вычислений.

**STRETCH**: выделите прямую/открытую полилинию, выберите инструмент, нажмите на её вершину и новое положение. Создаётся одна Undo-транзакция. Не поддерживает сложные многосегментные сплайны и групповое рамочное растяжение AutoCAD.

**MIRROR**: выделите POINT/LINE/открытую POLYLINE/CIRCLE, укажите две точки зеркальной оси. Создаётся отдельная редактируемая копия, оригинал сохраняется.

**ARRAY**: выделите допустимый геометрический объект и в панели «Инструменты» задайте четыре значения через точку с запятой — колонки, строки, шаг X, шаг Y. До 100 элементов всего (99 новых копий), с подтверждением.

Новые и изменённые объекты не получают verified=true; все координаты до калибровки условные. Функции намеренно ограничены примитивами без ассоциативных размеров, штампов, ESKD и произвольных 3D-структур. Тесты src/geometryTransform.test.ts, e2e/w4-editor.spec.ts.
