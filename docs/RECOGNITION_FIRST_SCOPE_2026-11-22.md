# CadRecon: зафиксированный продуктовый фокус — 2D PDF/сканы → редактируемый CAD

**Решение пользователя от 22.11.2026. Имеет приоритет над историческими W4/W7, 3D и CAD-моделированием.**

## Входит в продукт

1. Нативные PDF: извлечение без повторной трассировки векторов, типизированные LINE/POLYLINE/ARC/CIRCLE/ELLIPSE/SPLINE, корректные координаты, clipping, слои и текст. Неподдерживаемые формы и потери — явные предупреждения.
2. Сканы PDF/PNG/TIFF/JPG: максимальная сохранность пикселей, 2D обводка линий/контуров, штриховых/осевых, окружностей и дуг, OCR русских/английских надписей, размеры и ЕСКД-кандидаты; контролируемые ресурсы CPU/RAM.
3. Контроль неопределённости: отсутствие автоматического подтверждения, отчёт о возможных потерях, слабой опоре на чернила, неверных типах штриховки, OCR-конфликтах, масштабе и разрывах; до/после и ручная коррекция.
4. DXF R2000 как основной выход; JSON/ZIP для локального архива. Внешние DWG/CDW — только через отдельно установленную пользователем легальную 2D CAD-систему, не собственным сервером.
5. GitHub Pages — единственный хостинг; вычисления, OCR и PDF пользователя только в его браузере, опциональный Ultra устанавливается на его ПК. Никакого собственного сервера.

## НЕ входит в продукт

- **Никакой 3D-модели, 3D-построений, проекций из 3D, STEP, SLDPRT, SLDASM, A3D/M3D, 3D-САПР-геометрии.**
- Новые чисто чертёжные инструменты, не связанные с исправлением результатов распознавания, не являются приоритетом развития.
- Нативная запись DWG/CDW средствами GitHub Pages без лицензированной локальной CAD-системы не обещается.

## Порядок работ

- **P0 W1:** PDF vector import, paint/clip/XObject/mixed PDF, подтверждённые геометрические точности и экпорт DXF.
- **P0 W3:** недопуск потери тонких/близких линий, распознавание штриховых и осевых, устранение избыточных гипотез без ложного соединения зазоров, качество изображения, OCR.
- **P0 W2:** критичные цифры/допуски/штамп, типы шрифтов, bbox и контролируемое повторное распознавание.
- **P1 QA:** самостоятельные размеченные разрешённые эталоны и измерение true precision/recall, CER/WER и отклонений PDF→DXF; независимые round-trip, без заявлений «100%».
- **P1 UI:** единый сценарий загрузка → распознавание → сравнение/верификация → экспорт. CAD-редактор остаётся вспомогательным.

## Принятые ограничения

Реальные сканы не гарантируют полного восстановления потерянных/засвеченных линий. Балл алгоритма и опора на пиксели не являются вероятностью корректного инженерного объекта. Без подтверждённого масштаба никакие пиксели не принимаются за миллиметры. DXF из OCR/обводки требует проверки инженером.
