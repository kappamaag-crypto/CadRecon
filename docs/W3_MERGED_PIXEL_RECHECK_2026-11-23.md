# W3 — повторное измерение пиксельной опоры после сшивки Hough LINE

**23.11.2026.** Основной режим — GitHub Pages, без собственного сервера; распознавание и вся проверка происходят на устройстве пользователя. Изменение связано с [issue #6](https://github.com/kappamaag-crypto/CadRecon/issues/6).

## Исходный дефект

При объединении перекрывающихся фрагментов Hough меняется геометрическая длина LINE. Показатели inkSupport/blankRunRatio для исходного короткого фрагмента нельзя переносить на весь результат. Ранее система правильно удаляла устаревшее свидетельство и помечала его неизвестным. Следующий этап — безопасно измерить опору заново **по исходному скану**, а не вычислить её из старых процентов.

## Реализация

- После консервативного объединения в подробном режиме отбираются только неподтверждённые trace LINE с причиной «опора итогового отрезка не пересчитана».
- Из локального изображения через Canvas строится горизонтальная полоска 9 пикселей шириной до 512 точек вдоль **всей объединённой геометрии**. Не создаётся отдельный RGBA буфер полной страницы A0.
- Применяется адаптивный порог Otsu и повторная оценка опоры, самого длинного непрерывного отсутствующего штриха. Возвращаемая длина разрыва — в пикселях **обработанного растрового источника**, а не в CAD-миллиметрах.
- Confidence может быть только понижен или сохранён, никогда повышен; статус verified всегда false.
- Обработка не более 400 объединённых LINE, с уступкой event loop для отзывчивости. Невозможно измерить или отменено — старое неизвестное свидетельство не подменяется угаданной цифрой, пользователь получает предупреждение.
- Нет изменения точек/достраивания пропущенных линий; это **оценка кандидатов**, а не исправление чертежа.

## Проверки

Unit: проверка нового свидетельства и исходных координат, отсутствие повышения confidence, запрет auto-verified, управление лимитом и отсчёт по Canvas-полосе. Browser E2E/CI: общий synthetic W0/W3 regression, самостоятельный анализ DXF, сборка и URL GitHub Pages.

## Границы

- Цветная синяя разметка поверх исходника может сама стать «чернилами» в скан-детекторе. Такой тест не является независимой приёмкой: эталон должен быть размечен отдельно от исходного чистого скана.
- Максимум 512 выборок может не зафиксировать разрыв существенно меньше шага выборки на очень длинной линии. Система не обещает абсолютную точность.
- Риск ошибочного объединения/перекрестия, ложные Hough и точность OCR размеров **по реальным КМ/КМД** остаются P0; снижение недоказанного количества LINE не считается достижением.
- При нехватке ресурсов результат остаётся непроверенным, с возможностью ручного редактирования и отмены.
