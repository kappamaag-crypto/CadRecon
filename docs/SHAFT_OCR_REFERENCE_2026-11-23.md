# W2: проверка OCR на реальном частично размеченном чертеже — 23.11.2026

## Контрольный пример

Пользователь предоставил изображение **вала 1024 × 724 px** с основным видом, сечениями, размерами, резьбовыми обозначениями, техническими требованиями, рамкой и штампом. Поверх исходных линий нанесена **синяя/бирюзовая разметка**. Сам файл и содержимое чертежа не добавлены в публичный GitHub и не нужны для воспроизведения открытых unit/E2E-тестов.

Поскольку цветные линии одновременно являются частью обрабатываемого растрового изображения, считать распознавание этой же синей обводки независимым доказательством правильной геометрии **нельзя**. Для строгого эксперимента нужна исходная необведённая версия + независимо перепроверенные bbox/LINE/CIRCLE. Синяя разметка — только ориентир для ручной проверки.

## Новый формат OCR эталона

```json
{
  "version": 1,
  "reviewed": false,
  "scope": "partial",
  "imageWidth": 1024,
  "imageHeight": 724,
  "labels": [
    {"id":"sample-size","text":"300","x0":200,"y0":200,"x1":240,"y1":220}
  ]
}
```

Координаты здесь **исключительно фиктивный пример формата**, не утверждённая локализация надписи на реальном валу. Для импорта после индивидуальной проверки координат и значения каждой строки замените `reviewed:false` на `reviewed:true`.

- `scope:"partial"`: измеряются обнаружение, CER/WER и точный match критических токенов на размеченных надписях. Precision и число ложноположительных по всему листу **не вычисляются**, поскольку штамп, рамка, технические требования и остальные надписи могут не быть размечены.
- `scope:"complete"`: требуется `region` в исходных пикселях, например `{"x0":10,"y0":10,"x1":200,"y1":100}`, и **все** надписи внутри этого прямоугольника должны быть размечены. Precision ограничивается **этой областью**, за её пределами ложноположительные не подсчитываются.
- `imageWidth/imageHeight` должны **точно** совпадать с локальным сканом. Данные не отправляются на сервер.
- Старые массивы `[{id,text,x0,y0,x1,y1}]` разрешены для совместимости, но считаются `legacy`, без precision по непроверенной области.
- Размерные знаки `Ø`, `⌀`, `×`, `±`, `Rz`, `Ra`, кириллица и латиница не заменяются автоматически: любая ошибка в символе остаётся ошибкой токена.

## Цель инженерной приёмки

1. Отдельно измерять подмножества: диаметры, линейные размеры, шероховатости, резьбы, допуски и основной штамп.
2. В отчёте хранить `scope`, bbox, знаменатель размеченных надписей, CER/WER и exact critical text. Не объявлять один агрегат «общая точность CadRecon».
3. Проверять оригинальный скан без синей наложенной обводки, при необходимости — несколько DPI и светлые копии.
4. Не включать частные КД в CI, публичные fixtures или логи. Использовать приватный локальный JSON-эталон.
