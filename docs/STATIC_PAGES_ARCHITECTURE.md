# Архитектура CadRecon: GitHub Pages + вычисления у пользователя

**Решение пользователя от 22.11.2026, имеет приоритет над прежними предложениями облачной W2.**

## Непересматриваемые ограничения

1. **Единственный хостинг приложения — GitHub Pages.** У проекта **нет собственного сервера**, облачного OCR API, очереди заданий, серверной базы, облачной обработки чертежей и абонентской платы за вычисления.
2. Все штатные функции — импорт/разбор PDF, обработка сканов, OCR, геометрия, ЕСКД-кандидаты, редактирование, сравнение, DXF/JSON/ZIP — выполняются **на устройстве пользователя внутри браузера**. GitHub Pages только выдаёт статические HTML/CSS/JS/WASM и необходимые ассеты.
3. Модели и дополнительные вычислительные пакеты пользователь **скачивает сам по необходимости**. Распространение весов/библиотек статическими GET-запросами не означает передачу чертежа на сервер; желательно хранить версии, размер/лицензию/SHA256 и кэш. Первая загрузка OCR RU/EN требует интернет-соединения; её выполняет Tesseract.js, сохранение между сеансами зависит от кэша браузера.
4. **Ultra Local — только необязательный пакет, установленный на ПК пользователя** (в будущем может быть отдельное desktop приложение). Он вправе запускать Python и локальный API на `127.0.0.1`/localhost; **любой внешний адрес в клиенте запрещён**. Пользователь не обязан устанавливать Ultra, чтобы пользоваться основной системой.
5. Файл КД не отправляется на чужой OCR-сервис. Возможные отдельные загрузки браузером: статические страницы, worker/WASM, языковые модели и обновления. Не обещать «полный offline» до гарантированного кэширования всех ресурсов/весов.
6. GitHub Actions используются только для сборки, тестирования и публикации статического сайта, **не для обработки загруженных пользователем чертежей**.
7. PDF→CAD, особенно из скана, не может гарантировать 100% автоматическую правильность размеров и контуров. Калибровка, неоднозначные элементы и проверка инженером остаются обязательными.

## Архитектурная схема

```text
                     GitHub Pages (статика)
                              |
                  HTML/CSS/JS/WASM/Workers
                              |
                     Браузер пользователя
               ┌──────────────┴────────────────┐
               │ PDF.js → native paths / TEXT   │
 PDF / скан →  │ Canvas + Worker → lines/arcs   │ → CAD model → DXF/JSON/ZIP
 (лок. файл)   │ Tesseract RU/EN → OCR candidates│
               │ ESKD, dimensions, review, Undo │
               └──────────────┬────────────────┘
                              |
                    IndexedDB / local backups
                              |
                необязательно: скачанный Ultra
                     localhost:8766 на этом ПК
                  (никогда удалённый OCR-сервер)
```

## Что уже реализовано в `main`

- PDF.js 5.x packed+legacy vector paths, цифровые надписи, Bezier/контур/окружности как CAD entities; browser-only формирование DXF.
- Для сканов: детальная тайловая обводка, Hough и распознавание окружностей, Tesseract.js RU/EN в Worker, поиск предполагаемых размерных цепочек/ЕСКД.
- **Кнопка «Точное распознавание в браузере»** запускает единый pipeline. Для PDF с достоверными native vectors не дублирует их растровыми линиями; для растровых источников объединяет обводку и OCR. Вторая кнопка заранее загружает RU/EN OCR-пакеты в текущем браузере.
- Предложения распознавания остаются `verified=false`; повторный запуск старается не плодить идентичные LINE/CIRCLE/TEXT/ESKD-кандидаты.
- Дополнительный блок Ultra в интерфейсе свернут, использует только localhost/127.0.0.1 с подтверждением; URL внешних OCR-серверов не принимаются. Перенаправления HTTP из локального модуля запрещены.
- Предыдущий `backend/online_server.py` не является облачным сервисом и может применяться **только как локальный API дополнительного модуля**; на GitHub Pages не запускается.

## Новая приоритизация

| Приоритет | Модуль | Что требуется |
|---|---|---|
| P0 | Quick Web / native PDF | Точный векторный разбор: CTM, clipping, paths, Bezier, текст, единицы, отчёт потерь |
| P0 | Accurate Web / сканы | Тайлинг, качество геометрии и OCR, распознавание размеров, уверенность, контроль повторов, ограничения памяти |
| P0 | Проверка и экспорт | Ручная правка, разница до/после, калибровка и DXF с независимой проверкой |
| P1 | Downloadable browser models | Явные размеры и лицензии, загрузка моделей по требованию, версия, кэш/очистка, WebGPU/CPU fallback |
| P1 | Offline/PWA | Кэширование app-shell, WASM/Workers/моделей и работа без сети после подготовки и проверки |
| P1 | UX и производительность | Большие листы, контроль RAM/GPU, worker cancellation, progressive previews |
| P2 | Ultra Local optional | Простой инсталлятор с выбором папки, CPU/GPU, локальный runtime и standalone updates |
| P2 | DWG/CDW | Только лицензированный сторонний SDK/коннектор, не обязательный для GitHub Pages |

## Отказ от прежнего cloud-плана W2

**Не реализовывать** SaaS, user accounts, multi-tenant storage, remote HTTPS inference, аренду GPU, серверный очередь/биллинг/регион хостинга. Эти задачи вычеркнуты из активной дорожной карты, даже если встречаются в исторических ADR/документах. Работы по W2 перенаправлены на **полностью браузерный Accurate mode + добровольно скачиваемые модели**.

Конфиденциальность — не обещание полной анонимности веб-запросов: браузер всё равно обращается за ресурсами к GitHub Pages/CDN. **Содержимое чертежа** остаётся локальным при использовании штатного режима; во время разработки это дополнительно проверяется E2E-тестом отсутствия POST/PUT/PATCH на импортируемом PDF.

## Не реализовано — честные ограничения

- Загрузка/обработка любых ONNX/WebGPU-пакетов, ручной импорт своих файлов весов и гарантированная полноценная автономная работа после первичной загрузки пока **не реализованы**. OCR RU/EN использует существующие Tesseract.js модели, скачиваемые по требованию.
- Не доказана точность на разрешённом независимом корпусе реальных чертежей; синтетические эталоны лишь выявляют конкретные ошибки.
- Локальный Ultra не обязателен и пока не доведен до универсальной one-click/zero-dependency установки.
- Нет нативной записи в DWG/CDW, гарантии сохранения всей CAD семантики, сертифицированного нормоконтроля ЕСКД.
