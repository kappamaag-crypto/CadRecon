# W0 — локальный независимый контроль геометрии по размеченным чертежам

**23.11.2026.** Работает полностью в браузере на GitHub Pages без отправки проектных чертежей или референсной разметки на сервер.

## Исходный чертёж для приёмочных испытаний

Пользователь предоставил PNG изображения вала 1024 × 724 пикселя с основным видом, сечениями, размерами и техническими надписями. На рисунке присутствуют синие линии обводки и бирюзовые маркеры. Сама раскрашенная иллюстрация НЕ доказывает точную и полную независимую разметку: часть цветных линий находится на рамке и штампе, часть CAD-сущностей не размечена. Поэтому оригинал остаётся локально у пользователя и не включён в публичный репозиторий.

## Как провести измерение

1. Откройте изображение в CadRecon и запустите детальную обводку.
2. В правой вкладке «Распознавание» откройте раздел «Сравнить LINE / CIRCLE с проверенной разметкой (локальный эталон)».
3. Скачайте пустой шаблон; он содержит реальные размеры подложки, пустые списки lines и circles и reviewed:false.
4. Внесите проверенные человеком координаты линий/окружностей в ПИКСЕЛЯХ исходного изображения и только потом поменяйте reviewed на true.
5. Для частичной разметки используйте scope partial — тогда посторонние линии на неразмеченной части листа не объявляются ложными. Для полной разметки используйте scope complete вместе с ограниченным region и внесите ВСЕ нужные линии/окружности в этой области.
6. Загрузите JSON обратно в программу; измерение не изменяет лист и не загружает данные в GitHub или сторонний OCR.

Пример структуры JSON (координаты УСЛОВНЫЕ, не относятся к валу и НЕ являются проверенным эталоном):

~~~json
{
  "version": 1,
  "reviewed": true,
  "imageWidth": 1024,
  "imageHeight": 724,
  "scope": "partial",
  "lines": [
    {"id":"example-line", "a":{"x":100,"y":100}, "b":{"x":180,"y":100}}
  ],
  "circles": [
    {"id":"example-circle", "center":{"x":400,"y":300}, "radius":20}
  ]
}
~~~

## Что измеряется

- Покрытие эталонных LINE долей вдоль длины, включая случаи, когда одна правильная линия восстановлена несколькими фрагментами. Угол согласованности 7,5°, геометрический допуск 3 пикселя; max 128 интервалов выборки.
- Число эталонных LINE, покрытых не менее чем на 90%, и список непокрытых.
- Кандидаты CIRCLE: сопоставление центра и радиуса с геометрическим допуском, средние абсолютные ошибки в пикселях.
- При частичной разметке число ложных LINE и окружностей неизвестно: нельзя вычислить достоверную precision.
- При полностью размеченной ограниченной области показывается приблизительная согласованность кандидатов, не formal object precision или F1.
- Ручные правки исключены из метрик алгоритма: участвуют только объекты PDF/автообводки. Исходная геометрия никогда не меняется.

## Область применения и границы

Максимум 250 линий и 100 окружностей в эталоне, 10000 сравниваемых сегментов. Результаты выражены в исходных пикселях, НЕ в мм без независимой калибровки. Для сложных кривых, дуг, выносок и семантики размеров нужны отдельные правила. Цветные линии над изображением не превращаются автоматически в утвержденный эталон.

Следующий шаг: на локальной копии размечать контур вала, пазы, сечения, осевые и размеры отдельными классами, а затем измерять покрытие, пропуски и ложные сегменты на новых реальных чертежах. Для проверки текстовых значений используйте существующий OCR JSON benchmark. Ручная проверка CAD/DXF остаётся обязательной.
