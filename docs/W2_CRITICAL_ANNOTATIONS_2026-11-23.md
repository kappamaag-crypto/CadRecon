# W2 — точечный OCR-контроль технических обозначений вала

**23.11.2026.** Важен не общий балл Tesseract, а сохранение символов размеров, допусков, резьб и шероховатости. Пример: детали «Вал» с надписями Ra/Rz, Ø/⌀/∅, резьбой M20×1,5 и допуском ±.

## Изменения

- В `assessTechnicalOcr` добавлен флаг `criticalLabel` для типичных технических сочетаний (Ra/Rz с числом, диаметр, резьба с явно указанным шагом, ± с числом), независимо от OCR confidence. **Это не сигнал об ошибке**, а приоритет инженерной проверки.
- В усиленном браузерном OCR такие надписи перечитываются локально отдельным увеличенным фрагментом, когда confidence менее 0.90. Повторы остаются под общим лимитом maxRetries, без скачивания новых моделей и без передачи чертежа серверу.
- Разночтения сохраняются как альтернативные кандидаты с явной пометкой «КОНФЛИКТ OCR»; автоматической замены «Ra 0,8» на «Ra 0,6» не допускается.
- В блоке проверки добавлено число критичных OCR-надписей, ещё не подтверждённых вручную. Оно не заменяет показатель слабого confidence и не создаёт инженерный статус verified.
- Примеры полей взяты для **регрессионных синтетических тестов**, но реальные значения приложенного изображения необходимо независимо проверить на оригинале.

## Пределы

Обычное число 300 без символов не может быть доказательно классифицировано как технический размер только по тексту. Не заявлять, что этот механизм полностью определяет значения допусков, размерные цепи или правила ЕСКД. Для реального CER/WER и критической точности нужна разметка bbox по исходному чистому чертежу. Программный классификатор не знает, правильно ли прочитал Tesseract.
