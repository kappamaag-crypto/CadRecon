# CadRecon W4 — матрица реализованных и недостающих CAD-функций

Состояние main, 22 ноября 2026. Основной CadRecon — статический GitHub Pages, вычисления в браузере. Единицы чертежа не являются миллиметрами до проверенной калибровки.

## Работа с новой боковой панелью

Вкладка «Инструменты» содержит поиск CAD-команд (Ctrl+K / Cmd+K), группы по назначению, избранные команды (звёздочка), расширение и сворачивание панели. Избранное пока сохраняется только на время работы интерфейса. На мобильном экране панель работает как перекрывающая чертёж боковая область.

## 1. Геометрия

- Реализовано: точка, отрезок, штриховая/осевая линия, полилиния, прямоугольник по двум углам и по центру, окружность по центру и радиусу или по 3 точкам, дуга по центру/двум направлениям либо по трём точкам, эллипс по двум полуосям, вписанный/описанный правильный 3–128-угольник, кубическая Безье (4 узла).
- Вспомогательные бесконечные горизонтальные, вертикальные, наклонные и биссектрисные прямые отображаются в границах листа и не выводятся в DXF.
- DXF: CIRCLE, ARC, ELLIPSE, LWPOLYLINE, SPLINE, LINE; без превращения всего в пиксели.
- Не реализовано: произвольные NURBS, комплексные касательные решения, OFFSET дуг/сплайнов и многосегментных полилиний, ГОСТ-штриховки металл/бетон/дерево с нормативной проверкой. Существующая HATCH пока только сплошная заливка.

## 2. Правка

- Было: ручные TRIM/EXTEND для ограниченных LINE, OFFSET, BREAK, JOIN, CHAMFER/FILLET двух отрезков, STRETCH вершины, MIRROR-копия, прямоугольный ARRAY.
- Добавлено: ROTATE вокруг опорной точки, SCALE с положительным коэффициентом, точный MOVE по Delta X/Delta Y, SHEAR по X для прямолинейной геометрии, круговой ARRAY (2–64 элемента), разовое выравнивание LINE по горизонтали/вертикали. Все изменения делаются одной Undo-транзакцией и сбрасывают verified.
- Сдвиговая деформация окружностей/дуг отвергается, чтобы не экспортировать ошибочный CIRCLE/ARC. Нет полной автоматической правки соприкасающихся объектов, массива вдоль кривой и многоконтурного OFFSET.

## 3. Размеры

- Выровненные размеры по 2/3 точкам, горизонтальные и вертикальные проекционные DIMENSION, автоматические кандидаты по LINE/CIRCLE. Для некалиброванного чертежа текст значения — вопросительный знак, не мнимые миллиметры.
- Для выбранной окружности есть R- и диаметровая выноски, две оси центра. R и диаметр пока выпускаются в DXF как LINE+TEXT, а не нативные DIMRADIUS/DIMDIAMETER.
- Не готово: ассоциативное обновление размеров, полноценные угловые DIMENSION, базовые и цепные серии, размер с обрывом, управляющие размеры.

## 4. ЕСКД-оформление

- Имеются редактируемые знаки сварки, шероховатости, баз, геометрических допусков, разрезов/выносных знаков, резьбы, уклона, конусности (12 вариантов), текст, таблица, основная надпись, выноски и центрирующие оси.
- Добавлена вставка нумеруемых технических требований отдельными текстовыми CAD-сущностями.
- Нормативная полнота ЕСКД и проверка по актуальным ГОСТ для каждого символа и штриховки не подтверждены.

## 5. Виды из 3D

НЕ реализовано. Нельзя правдоподобно восстановить исходную 3D-модель из одного изображения/векторного PDF. Главные виды, разрезы, проекции, локальные виды и разрывы требуют полноценной 3D-геометрии и отдельного геометрического ядра либо лицензированного локального коннектора КОМПАС-3D v25 (W7). В облачный сервис чертежи не отправляются.

## 6. Ограничения/параметризация

Доступны только разовое выравнивание LINE и точное ручное соединение по совпавшим концам (JOIN). Это не сохраняемые параметрические связи. Полный solver для касания, совпадения, концентричности, равных радиусов и управляющих размеров ещё не написан.

## 7. Измерения и диагностика

- В свойствах объекта показываются длина, периметр, радиус и площадь там, где они однозначны. Площадь эллипса точная, периметр — приближение Рамануджана II. Открытая полилиния не имеет площади.
- Инструмент измерения ориентированного угла между двумя LINE не изменяет геометрию.
- В «Аудите» — свободные концы, точные дубли, близкие соосные разрывы и количество замкнутых полилиний; диагностика не исправляет контуры автоматически и не заменяет проверку пригодности к выдавливанию.

## Проверка

Unit: cadPrimitives, affineCad, cadMeasurements, cadAnnotations, core. Браузер: e2e/w4-editor.spec.ts. Независимый DXF-парсер ezdxf проверяет ELLIPSE, DIMENSION и отсутствие вспомогательных XLINE. Реальный CAD round-trip в КОМПАС/AutoCAD и корпус размеченных производственных КМ/КМД остаются открытыми P0.
