# W1/W3 — достоверность распознавания PDF и выцветших сканов (22.11.2026)

## Цель

CadRecon обрабатывает только плоские PDF/PNG/JPEG/TIFF-чертежи и сохраняет редактируемый **2D DXF**. 3D полностью исключено. Вычисления выполняются в браузере с GitHub Pages; опциональный Ultra — только на компьютере пользователя.

## Векторные PDF, W1

- Обязательно извлекать исходные PDF paths, не переводя настоящие векторы в шумную raster Hough-трассировку без просьбы пользователя.
- Распознаются окружности по четырём кубическим четвертям и **истинные эллипсы** с проверкой ортогональности полуосей и значения нормированного квадратичного уравнения. Кривые с высоким остатком остаются редактируемыми SPLINE, а не выдаются за точную окружность.
- Прямоугольный PDF clipping отсекает LINE и **кубические кривые Безье** по точным параметрическим интервалам алгоритмом de Casteljau. Выход остаётся DXF SPLINE без аппроксимации прямыми; частично видимые окружности и замкнутые контуры не экспортируются как полностью замкнутые. Исправлена реальная последовательность PDF.js `constructPath / clip / endPath`; настоящая синтетическая PDF→DXF проверка пройдена. Произвольные clipping, вложенные Form XObject и альфа всё ещё не реализованы.
- Растеризация PDF сохраняется прежде всего как **PNG без потерь**, чтобы не ухудшать тонкие линии и OCR. Лишь при ограничении памяти — JPEG с явным предупреждением. Для смешанного векторного PDF со встроенными изображениями программа предлагает гибридный режим.

## Сканы, W3

- Порог распознавания пикселей теперь определяется по Otsu **на каждом оригинальном тайле**, а не фиксированным условием «чернее 165». Важна граница `gray <= threshold`: если бледная линия совпадает с порогом, она не исчезает.
- Этот порог согласован между Hough, проверкой периодичности DASHED/CENTER, централизацией штриха, пиксельной оценкой опоры, удалением дублей и поиском окружностей.
- Прозрачные пиксели PNG компонуются на белом фоне перед трассировкой: альфа=0 не становится ложным чёрным штрихом.
- Сохраняются отдельные гипотезы SOLID/DASHED/CENTER; близкие линии с отдельными контурами не удаляются только из-за схожего геометрического ключа.
- В модели `scanEvidence` сохраняются доля опоры на источник, наибольшая доля белого пробела и число повторяющихся штрихов (если выявлено). Это **не вероятность достоверности**.

## Дополнительная фильтрация W3

Кнопка «Найти и удалить явно слабые линии» не запускается автоматически. Только неподтверждённые SOLID LINE, полученные из scan trace, с `inkSupport <= 0.12`, `blankRunRatio >= 0.40`, `confidence <= 0.20` могут быть предложены к удалению. Пользователь видит предупреждение, подтверждает и может нажать Ctrl+Z. Бледный/повреждённый реальный штрих всё ещё может удовлетворять порогам, поэтому сначала **сравните до/после**. Нативные PDF, ручные, DASHED/CENTER, подтверждённые линии не удаляются.

## Приёмка

- Unit-тесты: `src/pdfBezierClip.test.ts`, `src/edgeOrientation.test.ts`, `src/ocrRisk.test.ts`, `src/pdfPaths.test.ts`, `src/pdfRasterPolicy.test.ts`, `src/scanInkThreshold.test.ts`, `src/traceCleanup.test.ts`, `src/recognitionQuality.test.ts`.
- Browser E2E: `e2e/w1-clipped-curves.spec.ts` (настоящий PDF.js), `e2e/w1-lossless.spec.ts`, `e2e/w3-faded-ink.spec.ts`, `e2e/reconstruction-workflow.spec.ts`, старые W0/W1/W3 golden regression.
- Synthetic gray185-on-paper250 подтверждает воспроизведение бледных SOLID и DASHED; числа автоматически найденных кандидатов **не равны точным корректным геометрическим объектам**.
- Необходимо отдельно замерять precision/recall для линий/окружностей/штрихов/размеров и CER/WER для OCR на лицензированном наборе реальных чертежей с эталонным DXF и координатами. Отсутствие таких данных запрещает заявлять высокие проценты точности.

## Следующий P0

1. Убрать ложные Hough-кандидаты без снижения полноты тонких/соседних деталей. Текущий искусственный тест **даёт сотни гипотез из очень немногих реальных линий**, поэтому качество ещё не готово к автоматической выдаче без ревью.
2. Полные PDF Form XObject/произвольное отсечение/графические состояния без скрытой потери геометрии.
3. OCR размерных надписей, вертикального текста, ГОСТ-знаков и штампов: таблица конфликтов, bounding boxes, critical-digit errors.
4. Удобный слой ревью: дифф по областям, подсветка несопоставленных элементов и ручная точная коррекция, затем DXF export validation в установленной 2D CAD.
