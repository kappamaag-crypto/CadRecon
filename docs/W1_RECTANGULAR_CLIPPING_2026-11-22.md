# W1 — точное прямоугольное PDF clipping: LINE, Bézier, CIRCLE и контуры

Область применения — только редактируемая плоская геометрия PDF, в браузере GitHub Pages, без сервера. Исходные чертежи не выгружаются в облако.

## Реализовано

- **LINE:** отсечение доказанным осевым прямоугольником PDF W через Liang–Barsky. Геометрия, полностью вне видимой области, не экспортируется.
- **Кривые Безье:** `src/pdfBezierClip.ts` находит параметрические интервалы пересечения кубической кривой с границами x/y прямоугольника, учитывает критические точки производной и делит сегменты по de Casteljau. Видимые участки сохраняются в CAD как редактируемые кривые и в DXF как native SPLINE, а не как набор прямых.
- **Частично видимые CIRCLE/ELLIPSE:** если исходный контур описан четырьмя кубическими четвертями, нельзя экспортировать целую окружность, когда PDF отсекает её часть. В этом случае восстанавливаются только видимые SPLINE-участки.
- **Замкнутые полилинии:** если их исходные линии пересекают границу clipping, в DXF остаются только видимые исходные сегменты; замыкание вдоль границы не выдумывается.
- **PDF.js:** поддерживаются `constructPath(END_PATH) → clip` и `clip → constructPath(END_PATH)`, packed и legacy rectangle с проверкой четырёх углов, корректное сохранение/восстановление q/Q.

## Проверка реальным PDF.js

`benchmarks/w0/generate_fixtures.py` создаёт `native_clipped_curves.pdf` с тремя операциями W n и исходными окружностью, кривой и прямоугольником. `e2e/w1-clipped-curves.spec.ts` импортирует настоящий PDF в браузере, проверяет 5 редактируемых Bézier и 2 видимые прямые, отсутствие целой CIRCLE/LWPOLYLINE и экспорт native SPLINE в DXF.

Проверка выполнена в [успешном GitHub Actions Build and Test](https://github.com/kappamaag-crypto/CadRecon/actions/runs/45051344640). Существующие `src/pdfPaths.test.ts` и `src/pdfBezierClip.test.ts` дополнительно проверяют числовые границы, пересечения, отсутствующие части и q/Q.

## Незакрытые P0

Произвольные clipping path и even-odd со сложными подконтурами, вложенные Form XObject, непрозрачность и графические маски, взаимодействие сложной заливки с clipping, PDF шрифты и инженерные единицы, а также независимые тесты на законных реальных КМ/КМД остаются открытыми. При невозможности доказать геометрию CadRecon показывает предупреждение, не `verified=true`.
