# W1: прямоугольное PDF clipping для нативных LINE (ограниченная реализация)

CadRecon остаётся браузерным GitHub Pages приложением. Новая проверка внутри `src/pdfPaths.ts` умеет извлекать четырёхугольную прямоугольную область `W n` из PDF.js packed path при условии точного совпадения всех четырёх осевых углов. Извлекаемые LINE внутри этого графического состояния обрезаются алгоритмом Liang–Barsky. Сохранённые/восстановленные PDF графические состояния q/Q восстанавливают область отсечения.

Задача не закрыта полностью: общий eoClip, не-прямоугольные clipping path, вложенные XObjects/прозрачность и истинная кривая остаются без геометрического отсечения и помечаются предупреждением. Если прямоугольник не подтверждён, исходный кандидат остаётся с предупреждением, а не удаляется без основания.

Проверено на синтетике: линия, пересекающая прямоугольную границу; линия снаружи не экспортируется; q/Q не распространяет отсечение на следующие объекты. Нужно тестировать на законно разрешённых реальных PDF КМ/КМД.

Тесты: `src/pdfPaths.test.ts`, `e2e/w1-clipping.spec.ts`; независимый DXF-парсер CI.
