# W3: распознавание штриховых и осевых кандидатов на скане

Статическая GitHub Pages версия. Без облака и сервера.

Модуль src/linePattern.ts проверяет повторяющиеся тёмные участки вдоль исходной Hough-оси до дробления на короткие элементы. Он различает регулярную последовательность штрихов (`lineStyle=dashed`) и чередование длинного штриха с точкой (`lineStyle=center`). Проверка требует не меньше 4 штрихов и повторяемой структуры пробелов. Один разрыв, текстовый элемент, хаотические пропуски краски не считаются осевой линией.

В чертеже это остаётся отдельным редактируемым LINE с атрибутом стиля, а не нарисованным непрерывным контуром. Canvas выводит его с пунктиром или штрихпунктиром. DXF экспортирует явные LTYPE `DASHED` / `CENTER`. Для каждого автоматически найденного объекта `verified=false`, семантика обязана быть подтверждена инженером.

Ограничения: ложные линии возможны на таблицах, повторяющейся штриховке и размерных знаках; на повреждённых и малоконтрастных сканах узор может не пройти пороги. Подлинные ЕСКД-обозначения и шаги штрихов необходимо валидировать по независимым источникам. Тесты src/linePattern.test.ts и src/core.test.ts. Результаты синтетических benchmarks не заменяют real CAD/scan precision/recall.
