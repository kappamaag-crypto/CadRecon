# SearchTextApp и КОМПАС ГАЛС — реализованные функции CadRecon

Дата: 2026-11-22. Репозиторий: kappamaag-crypto/CadRecon, main.
Первоначальный статический аудит архивов — ARCHIVE_FEATURE_AUDIT.md.
Архитектура: только GitHub Pages, документы и вычисления локально в браузере.
Никакого выполнения EXE/VBA и никакого внешнего OCR/API для этих функций.

## Как использовать

1. Откройте https://kappamaag-crypto.github.io/CadRecon/ и загрузите PDF, скан либо проект JSON.
2. Для скана сначала сделайте OCR: поиск работает только с уже извлечённым текстом.
3. Справа нажмите «Поиск и аудит» (иконка ⌕) и выберите раздел.

### Поиск
Поиск по всем листам или текущему листу, регистр, фильтры по
тексту, размерам, позициям, выноскам, таблицам, техтребованиям,
сварке и штампам. Клик по результату выбирает объект и центрирует холст.
Буквальные дубликаты явно размеченных технических требований выводятся
отдельным списком. Ничего автоматически не удаляется.

### Аудит объектов
Реестр CAD-сущностей по листам, типам, слоям, источникам и статусу
инженерного подтверждения; длины, радиусы, координаты. Группы
окружностей показываются как кандидаты, но не называются доказанными
физическими отверстиями. Миллиметры только на калиброванном листе.
Экспорт CSV и XLSX.

### Спецификация
Импорт CSV/TSV/XLSX/XLSM. Минимальные столбцы «Позиция» и
«Наименование», дополнительно «Обозначение», «Количество», «Материал»,
«Масса», «Примечание». XLSX и XLSM читаются только из Office XML в
браузере; макросы, ActiveX, формулы и удалённые ссылки не исполняются.
Используются записанные значения ячеек: кэш формул может быть устаревшим.
Нет поддержки зашифрованных файлов и бинарного XLS.

Сопоставляются только явные обозначения «Поз. 12» и целые номера
в выносках, а не произвольные числа в OCR. Расхождения: позиция из
спецификации не найдена, лишняя позиция на чертеже, дубли в документах.
Повторы на разных видах могут быть допустимыми. Сверка НЕ проверяет
количество деталей и НЕ восстанавливает ассоциативность нативной 3D-сборки.

### Сварка
Группировка явно созданных сварных символов ЕСКД и выносок с
подписями «шов»/«сварн». Считаются метки, а не физические места сварки.
Экспорт CSV/XLSX, количество непроверенных обозначений. Автоматических
утверждений ГОСТ и нормоконтроля нет.

### Основная надпись
Поля обозначения, наименования, изменения, листа, разработчика,
проверяющего, техконтроля, нормоконтроля, утверждающего, даты и
предприятия. Предпросмотр нового и старого текста; применение только
после подтверждения. Текущий или все листы, один Undo.
Создаётся редактируемый текстовый штамп; соответствие форме ЕСКД
не обещается и инженерное подтверждение сбрасывается.

### Файлы КОМПАС
После явного выбора файлов анализируются ТОЛЬКО имена:
A3D/M3D/CDW/SPW/STEP/STP/SLDPRT/SLDASM/PDF/DXF/DWG.
Пример: «АБВГ.01.100 - Опора.a3d» → предлагаемое обозначение и
наименование, предварительный просмотр и CSV-реестр.
Файлы не открываются, не изменяются и не отправляются на сервер.
Запись в свойства деталей/сборок/чертежей требует отдельного
локального коннектора и проверенного лицензированного КОМПАС SDK.

### Пакет проекта
Скачать DXF листов, отчет по объектам, сварке, спецификации,
расхождениям CSV, сводный XLSX, JSON проекта при допустимом
объеме и README в одном ZIP. Присутствуют шаблоны каталогов
КОМПАС, SOLIDWORKS, STEP, PDF и Архив. Нативные CAD/3D файлы
и исходные PDF не выдумываются из отсутствующих данных.

## Безопасность

- Excel read-only: ZIP/XML с ограничениями размера и числа строк, запрет
  XML DTD/entity. VBA и формулы не запускаются; старые книги XLS не читаются.
- CSV защищает от интерпретации пользовательского текста как формулы Excel.
- XLSX хранит текст в безопасных буквальных inline-string ячейках; никаких макросов.
- Все изменения штампа проходят предпросмотр и Undo, новые/редактированные
  объекты никогда не получают автоматическое verified=true.
- Из приложенных чужих EXE, VBA и словарей не копировался код или нормативная база.
- GitHub Pages не получает доступ к COM: нативная интеграция с КОМПАС-3D v25
  является отдельной задачей с лицензией и локальным ПО.

## Исходный код и тесты

- src/archiveFeatures.ts — поиск, CSV, геометрия, позиции, сварка, штампы, имена файлов.
- src/ArchivePanel.tsx — интерфейс семи разделов.
- src/specWorkbook.ts — безопасное чтение XLSX/XLSM.
- src/xlsxExport.ts — формирование Excel отчёта без макросов.
- src/zip.ts — пакеты с безопасными путями и бинарными вложениями.
- src/Editor.tsx — центрирование и подсветка найденного объекта.
- src/archiveFeatures.test.ts — unit tests.
- e2e/archive-workspace.spec.ts, archive-xlsx.spec.ts,
  archive-xlsm-import.spec.ts, archive-filenames.spec.ts — браузерные проверки.

### Открытые ограничения

Инженерная валидация на разрешенных реальных КМ/КМД, калибровка,
precision/recall сканов, полное PDF clipping/XObject, W3 избыточные
фрагменты LINE, версия нормативов и независимый DXF/CDW round-trip
по-прежнему необходимы. Успешные синтетические тесты не заменяют
нормоконтроль и не доказывают 100% распознавание произвольного чертежа.

### OCR-устойчивый поиск (дополнение)

Во вкладке «Поиск» появилась отдельная опция «OCR-допуск». Она сопоставляет распространённые визуально одинаковые кириллические и латинские буквы (например, М/M, С/C, Р/P), а также пропуски/добавления пробелов и точек между символами. Это вспомогательная функция поиска: похожее совпадение явно помечается, исходный текст и его verified не изменяются. Цифры 0/1 **не** заменяются похожими буквами. Режим выключен по умолчанию, потому что возможны ложные совпадения. Проверки: archiveFeatures.test.ts и archive-workspace.spec.ts.
