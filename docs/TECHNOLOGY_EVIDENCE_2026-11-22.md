# Технологии, аналоги и лицензии — доказательная матрица

Проверка документации: **2026-11-22**. Ссылки ведут к разработчикам/официальным сервисам. Изучение документации **не равно** испытанию реальными чертежами; никакому продукту не приписывается точность без benchmark. Для сторонних сервисов не отправлять пользовательские конфиденциальные чертежи без договора и явного согласия.

## Предлагаемый технологический стек, подлежащий PoC и ADR

|---|---|---|

| Открытый CAD | DXF, независимый парсер [ezdxf](https://ezdxf.readthedocs.io/) | Valid entity types, Unicode, units, dimensions, hatch, blocks, provenance, 2D round-trip |

### Решения для продукта

1. **Online-first**: быстрый browser-only разбор векторных PDF; основной «Online Accurate» — загрузка только по осознанному согласию, асинхронная очередь, тайлинг, ensemble, ревью. Для закрытой КД — browser-only либо Ultra.
2. **Model benchmark before adoption:** сравнивать версии PaddleOCR, OpenCV и сторонних API на одном locked gold corpus. Интеграция не повышает качество «по названию».
3. **Коммерческие API не делать критической зависимостью**. Выход DXF и подтверждение размерных цепей работают без сторонних платных услуг.
4. **Лицензии, законность, места хранения/TTL:** отдельный ADR для каждого облачного провайдера и SDK.
5. **Условия и доказательства:** фиксировать ссылку, дату проверки, тестовый образец, версию, тариф/лимит, допустимость обработки коммерческой КД, итог вердикта PoC.
