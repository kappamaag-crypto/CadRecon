# CadRecon — работа с чертежами, размерами и новыми инструментами

## Закрыть лист и не потерять работу

В верхней полосе листов рядом с названием каждого листа нажмите **×**. Подтвердите действие. Перед удалением листа из текущего проекта создаётся локальная резервная копия, а операцию можно отменить кнопкой «Отмена» или Ctrl+Z. Если закрыт единственный лист, редактор оставляет новый пустой. Для постоянного хранения используйте «↓ JSON» на диск; локальные резервные копии зависят от браузера.

## Штриховые и осевые линии

После «Детальная обводка» найденные по регулярной растровой структуре линии получают стиль «Штриховая» (DASHED) или «Осевая / штрихпунктирная» (CENTER). Для исправления выберите LINE инструментом ↖ → вкладка «Свойства» → «Тип линии (DXF)». Там же можно вернуть сплошную линию. Чтобы чертить штриховую вручную, выберите инструмент «Штриховая линия (DASHED)» слева. Осевая линия доступна отдельным инструментом в левой панели.

## Размер вручную

«Размер по двум точкам»: выберите начальную и конечную точки. «Размер с размещением (3 точки)»: укажите начало, конец, затем место размерной линии. Без калибровки числовое значение будет «?». Калибруйте лист по независимому известному размеру, дополнительно проверьте ещё один размер и координаты по оригиналу. Примечание: эти размеры не имеют полной ассоциативной параметрической CAD-системы.

## Авторазмеры

Выделите линию/окружность и в правой панели «Инструменты → Размеры и авторазмеры» нажмите «Авторазмер выбранного объекта». Для массового предложения — «Авторазмеры линий и окружностей», максимум 200 за одну операцию. Повторы для уже связанного `sourceId` пропускаются; линейные осевые/штриховые типы намеренно не подбираются автоматически. Кандидаты остаются непроверенными. Окружность получает текстовую выноску диаметра; это не полноценный нативный параметрический размер AutoCAD/КОМПАС.

## STRETCH, MIRROR, ARRAY

Сначала инструментом «Выделение» щёлкните по объекту. STRETCH — выберите ближайшую вершину, затем её новое положение; MIRROR — укажите две точки зеркальной оси; ARRAY — в панели инструментов введите «столбцы;строки;шаг X;шаг Y», например `3;2;40;30`. Все новые/изменённые объекты требуют проверки по оригиналу. Сложные замкнутые и ассоциативные 3D-структуры не поддерживаются.

## Границы точности и конфиденциальности

Программа работает в браузере GitHub Pages: загрузки чертежей на сервер CadRecon нет. Дозагрузка OCR-моделей происходит по вашему запросу. Никогда не считайте результаты распознавания и автоматических размеров готовыми производственными КМ/КМД без ручной проверки. Нативная запись CDW/DWG доступна лишь в перспективе при лицензированном адаптере на вашем ПК.

## Дополнение: OCR проблемного текста

Для повторного чтения мелкого размера или основной надписи откройте «Инструменты → Распознавание текста (OCR)», выберите усиленное качество и при необходимости «Искать вертикальные надписи». Затем нажмите «OCR области — выбрать два угла рамки» и отметьте два противоположных угла области на листе. Подтвердите правильность извлечённых строк во вкладке проверки. Используется оригинальная подложка, а координаты кандидатов остаются в исходном листе. Для скана свыше 6 Мп выберите меньшую область.
