# Размерные инструменты CadRecon — W4

На GitHub Pages, без сервера, доступны два ручных инструмента: «Размер по двум точкам» и «Размер с размещением (3 точки)». В трехточечном режиме первые две точки определяют измеряемый отрезок, третья — поперечное смещение размерной линии. Объект сохраняется как редактируемый CAD DIMENSION. Текст числа появляется только после калибровки листа, иначе `?`.

В панели «Инструменты → Размеры и авторазмеры» появились создание кандидата размера по выбранной линии/окружности и пакетное создание по текущему листу (до 200 кандидатов). Линии со стилем CENTER/DASHED, оси и уже размеренные по `sourceId` объекты не переобрабатываются. Окружность получает выноску диаметра, а не фиктивный нативный DIMDIAMETER. Кандидаты никогда не получают `verified=true`.

Числа основаны на текущей геометрии CAD и калибровке; распознанные линии могут быть ошибочны, поэтому все размеры должны сверяться с оригиналом и стандартами ЕСКД. Гарантия независимой метрологической точности не предоставляется.

Проверки: src/dimensionTools.test.ts и e2e/w4-editor.spec.ts. Операции поддерживают Undo.
