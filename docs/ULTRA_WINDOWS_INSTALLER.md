# W6 — экспериментальная установка CadRecon Ultra Local на Windows 11

**Состояние:** предварительный CPU bootstrap, без подтверждённой установки на реальной Windows. Скрипты сохранены в GitHub, но **в этой задаче не выполнялись на пользовательском ПК**. Это не подписанный installer/MSIX и не гарантированный «один клик» на компьютере без Python.

## Что подготовлено

- [Install-CadRecon-Ultra.cmd](../Install-CadRecon-Ultra.cmd): запуск установки двойным щелчком (использует PowerShell только в текущем процессе, не изменяет системную политику).
- [scripts/install-ultra.ps1](../scripts/install-ultra.ps1): диалог выбора каталога (или аргумент `-TargetDir`), CPU-окружение Python 3.11, зависимости PaddlePaddle + OCR, директории `app/models/cache/projects/logs/config`, случайный bearer token и права доступа к нему.
- В выбранном каталоге создается `Start-CadRecon-Ultra.cmd`: запускает [single-tenant pilot](../backend/ONLINE_PILOT.md) на `127.0.0.1:8766`. Сервис **не** открывается в интернет.
- Пример структуры:

```text
D:\CadReconUltra\
  app\backend\
  app\.venv\
  models\
  cache\
  projects\
  logs\
  config\token.txt
  config\install.json
  Start-CadRecon-Ultra.cmd
```

## Запуск

Предварительно установить **Windows 11**, Python 3.11 с Python Launcher `py`, обеспечить 5 ГБ+ свободного места и интернет для первоначальных моделей. Установочные команды и вес моделей зависят от доступности репозиториев; для GPU-версии потребуется отдельный проверенный install-profile.

1. Скачать ZIP репозитория CadRecon либо `git clone https://github.com/kappamaag-crypto/CadRecon.git`.
2. Запустить **`Install-CadRecon-Ultra.cmd`** двойным щелчком. Выбрать папку и подтвердить создание подкаталога `CadReconUltra`. При недоступном Python/пакетах установка сообщит об ошибке и не выдаст успешный результат.
3. После установки открыть `Start-CadRecon-Ultra.cmd` из целевого каталога и убедиться, что процесс слушает локальный порт 8766.
4. В веб-приложении CadRecon (GitHub Pages или локальном `npm run dev`) открыть «Online Accurate», указать `http://127.0.0.1:8766` и вручную скопировать bearer token из `config\token.txt`; **не отправлять секрет в чат, issue, email**.
5. На первом проходе использовать **только искусственный или открытый тестовый чертёж**, подтвердить отправку и проверить результат в «До/после» и DXF. Пароль не сохраняется в браузерном проекте.
6. Завершить сервер закрытием терминала, исходные проекты сохранять отдельным JSON или локальным архивом.

Для неинтерактивной установки с явной папкой (при наличии Python 3.11):

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\scripts\install-ultra.ps1 -TargetDir "F:\CadReconUltra" -NonInteractive
```

**Важно:** если при GUI-выборе указать `F:\`, установщик создаст `F:\CadReconUltra`, а `-TargetDir` задаёт конечный путь напрямую. Каталоги с пробелами/кириллицей запланированы; совместимость пока не испытана на реальном Windows runner.

## Безопасность и эксплуатационные ограничения

- Сервис *только localhost* по умолчанию, token используется совместно с job capability, извне до проксирования недоступен.
- Запуск CMD с process-local `-ExecutionPolicy Bypass` означает, что пользователь должен предварительно проверить источник скрипта; **нельзя** скачивать и запускать неизвестные «репаки».
- Секрет генерируется криптографически случайным, на Windows ограничиваются ACL. Если назначение ACL не удалось, установщик прекращает работу, а файл удаляется. Не хранить секрет рядом с общедоступными архивами.
- OCR-данные в онлайн-пилоте хранятся только в RAM задачи и удаляются при DELETE, по TTL при запросе; **фоновая строгая очистка TTL пока не реализована**, принудительная отмена уже исполняющегося worker также ограничена.
- Вес моделей PaddleOCR может использовать иные cache paths, требующие настройки/проверки: папка `models` создается, но полная изоляция кэша пока **не подтверждена**.
- Автоматических подписанных обновлений, rollback, регулярных бэкапов, автоудаления зависимостей и offline model bundle ещё нет.
- Входной файл ограничен одной страницей и лимитами 25 МБ/42 Мп. Нет CAD DWG/CDW коннекторов или совместимости с КОМПАС SDK в этом пилоте.
