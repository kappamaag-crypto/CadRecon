# W3: восстановление центральной оси толстого растрового штриха

Дата: 2026-11-22. Архитектура: GitHub Pages, локальное вычисление в Web Worker.

Новый модуль src/inkCenterline.ts уточняет Hough-кандидаты LINE по **непрерывной связной полосе тёмных пикселей**, измеренной вдоль нормали. Поддерживаются штрихи шириной 2–9 пикселей. Если гипотеза проходит через белое пространство, она не переносится к соседнему контуру. Для устойчивости используются до 48 проб и робастная медиана с отбрасыванием пересечений.

Корректировка выполняется до удаления повторяющихся Hough-кандидатов; раздельные параллельные штрихи не притягиваются друг к другу. Confidence не повышается, автоматического verified=true нет. Итоговый отчёт сообщает число смещённых гипотез.

Негативные тесты: src/inkCenterline.test.ts — белый зазор, две параллельные линии, широкая полоса, пересечения, ошибочные данные.

Это только пиксельная геометрия: текст, штриховка и таблицы тоже содержат краску. Реальная инженерная точность в миллиметрах не доказана; необходимы независимые размеченные КМ/КМД.

## Безопасное ручное устранение повторов

Кнопка «Убрать дубли автоотрезков» теперь удаляет лишь почти соосные **действительно перекрывающиеся** LINE одного происхождения и слоя. Раздельные отрезки с положительным зазором, даже меньше прежнего допуска, не объединяются. При редактировании PDF-путей порог по поперечному направлению существенно жёстче, чтобы не стирать близкие детали. Применение требует подтверждения и резервного копирования. Добавлены отрицательные unit-тесты разрывов, близких параллелей и смешанного происхождения.
